🏥 Hospital Management System
📖 Description
A console-based C++ Hospital Management System that manages doctors, patients, appointments, medical reports, and departments using core Data Structures implemented from scratch.
🚀 Features

Doctor management — add, delete, and view doctors
Patient management — push/pop patient records using a stack
Appointment booking and serving via a queue system
Medical report storage and search using a Binary Search Tree
Department management using a Circular Linked List
File handling to log all records to sample.txt
Formatted console output with menu-driven navigation

🛠️ Technologies Used

C++
File Handling (ofstream)
Windows system functions (Sleep, getch)

🧠 Concepts Applied

Doubly Linked List — Doctor management (add/delete from both ends)
Stack (Linked List) — Patient records (LIFO push/pop)
Queue (Array-based) — Appointment scheduling (FIFO enqueue/dequeue)
Binary Search Tree (BST) — Medical reports (insert, search, inorder traversal)
Circular Linked List — Department management
Structs & Classes
Recursion (BST insert & search)
Dynamic Memory Allocation
File Handling
