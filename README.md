# 🏥 Hospital Management System

## 📖 Description
A console-based C++ Hospital Management System that manages hospital operations such as doctors, patients, appointments, medical reports, and departments using core data structures implemented from scratch.

---

## ✨ Features
- Doctor management (add, delete, view)
- Patient management using Stack (LIFO system)
- Appointment scheduling using Queue (FIFO system)
- Medical reports management using Binary Search Tree (BST)
- Department management using Circular Linked List
- File handling to store records in a file
- Menu-driven console interface

---

## 🛠️ Technologies Used
- C++
- File Handling (ofstream)
- Windows system functions (Sleep, getch)

---

## 🧠 Concepts Applied
- Classes and Objects
- Stack (Linked List implementation)
- Queue (Array-based implementation)
- Binary Search Tree (Insertion, Search, Traversal)
- Circular Linked List
- Doubly Linked List
- Recursion
- Dynamic Memory Allocation
- File Handling
